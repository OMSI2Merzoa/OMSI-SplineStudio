프로그램 소개

Spline Studio는 OMSI 2 및 openOMSI의 맵 제작에 사용되는 스플라인(SLI)을 보다 쉽고 편리하게 제작할 수 있도록 개발된 프로그램입니다.
기존에는 SLI 파일의 구조를 이해하고 좌표, 텍스처 매핑, AI 경로 등을 직접 수정해야 했지만, Spline Studio에서는 시각적인 편집 환경을 통해 이러한 작업을 진행할 수 있습니다.
간단한 도로부터 복잡한 도로 단면까지 제작할 수 있으며, 기존 스플라인을 불러와 수정하는 작업도 지원합니다.
초보 맵 제작자부터 숙련된 제작자까지 누구나 무료로 사용할 수 있습니다.


주요 기능
스플라인 제작 및 편집
- 기존 SLI 파일 불러오기 및 내보내기
- 2D 단면 편집 및 정밀 좌표 설정
- 도로 구성요소 기반의 스플라인 자동 생성
- 차로, 보도, 연석, 배수로 및 고정 폭 정류장 베이 제작
- 좌우 대칭 및 구성요소 연동
- 도로 횡단경사 설정
- 기존 스플라인을 기반으로 한 파생 도로 제작
- 스플라인 비교 및 다중 선택 편집

3D 미리보기
- 실시간 3D 미리보기
- 직선, 곡선 및 경사 구간 미리보기
- 다양한 카메라 시점
- 운전자 시점 미리보기
- 미리보기 이미지 저장

텍스처 및 재질
- 시각적인 UV 매핑 편집
- 텍스처 미리보기 및 즉시 적용
- 텍스처 매핑 프리셋
- 다중 텍스처 일괄 변경
- OMSI 2 및 openOMSI 대상별 재질 설정
- openOMSI용 PBR 리소스 관리

AI 경로
- 차량 및 보행자 경로 제작
- 우측통행 및 좌측통행 지원
- 도로 구성에 따른 AI 경로 자동 생성
- AI 경로 위치 및 방향 편집

프로젝트 및 리소스 관리
- 다중 스플라인 프로젝트 관리
- 프로젝트 공용 텍스처 관리
- 리소스 누락 확인 및 경로 재설정
- 스플라인 일괄 내보내기
- 배포용 ZIP 패키지 생성
- 프로젝트 백업 및 복원
- 자동 저장 및 복구

사용자 편의 기능
- 한국어 및 영어 지원
- 다크, 라이트, 시스템 테마
- 간편 제작 및 정밀 제작 모드
- 사용자 프리셋
- 기본 예제 프로젝트
- 내장 도움말
- GitHub 기반 자동 업데이트
- 포터블 실행 환경

지원 환경
| 항목 | 지원 환경 |
|---|---|
| 운영체제 | Windows 10 / 11 (64비트) |
| 지원 게임 | OMSI 2, openOMSI |
| 지원 언어 | 한국어, 영어 |
| 배포 방식 | 포터블 ZIP |
| 사용 비용 | 무료 |
| 별도 .NET 설치 | 필요 없음 |

다운로드 및 실행 방법
1. GitHub Releases 페이지에 접속합니다.
2. 원하는 버전의 SplineStudio ZIP 파일을 다운로드합니다.
3. 원하는 폴더에 압축을 해제합니다.
4. SplineStudio.exe를 실행합니다.
5. 최초 실행 시 기본 환경을 설정합니다.

별도의 설치 과정은 필요하지 않습니다.
