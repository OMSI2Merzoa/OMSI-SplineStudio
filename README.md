## 텍스처 경계 보정

- 신규 구성요소·전문가 신규 면·새 영역·자동 UV·U 초기화는 기본적으로 원본 0~1에서 **0.005~0.995**를 계산합니다. 좌우 반전은 방향만 바꿉니다.
- 선택 띠의 폭 W에 대해 양 끝을 W×M만큼 안쪽으로 옮깁니다. 예: 0.25~0.5, M=0.005 → **0.25125~0.49875**. M은 0 이상 0.5 미만이며 영역이 사라지는 입력은 거부합니다. V와 실제 형상·경로는 변경하지 않습니다.
- 원본 U 배열·보정 상태·최종 U 배열을 프로젝트에 저장합니다. 같은 원본에 다시 적용하면 같은 결과가 나오며, 보정을 끄면 원본으로 돌아갑니다. 출력과 3D는 실제 면에 기록된 최종 UV를 함께 사용합니다. 내보낼 때 추가 보정하지 않습니다.
- 기본 모드의 텍스처 카드와 전문가 UV 속성에서 보정 사용 여부·비율·원본/최종 범위를 확인하고 적용합니다. 아틀라스 편집기는 원본 띠와 안쪽 보정선을 구분합니다.
- 직접 입력하거나 드래그한 최종 UV에는 자동으로 추가 보정하지 않습니다. 범위 밖의 반복 UV는 신규 자동 보정에서 유지하며, 전문가 또는 일괄 적용에서 명시적으로 포함할 수 있습니다.
- 설정 창에서 신규 매핑의 기본 사용 여부와 비율을 저장합니다. 기존 문서에 소급 적용하지 않습니다.

## 기존 문서에 적용

**도구 > 텍스처 경계 보정 일괄 적용**에서 현재 표면/면, 구성요소, 여러 구성요소 또는 문서 전체를 선택합니다. 수동 UV 포함은 기본 해제이며 잠긴 면은 제외합니다. 전체 작업은 한 번의 실행 취소로 복원됩니다.

`2X2_test.sli`처럼 가져온 SLI를 보정하려면 문서 전체와 **수동 UV 및 범위 밖 반복 UV 포함**을 선택하세요. 현재 UV를 새 원본으로 보관하고 보정합니다. 원본 파일을 보존하려면 다른 이름으로 내보내세요. 이미 0.005~0.995인 외부 파일도 원래 보정 상태를 추측하지 않으므로, 사용자가 명시적으로 실행하면 현재 범위에서 추가로 안쪽을 계산합니다.

## 3D 표시 설정

3D 미리보기 제목줄 오른쪽 **◉** 버튼에서 텍스처·구성요소 경계·AI 경로/번호·정점/연결점·선택 강조·격자·축을 각각 전환합니다. 기본/전문/분할/확대 화면은 같은 설정을 사용하며 2D 표시에는 영향을 주지 않습니다.

- **편집용:** 텍스처·경계·경로·선택·격자·축 표시, 정점 숨김.
- **순수 스플라인:** 실제 메시와 텍스처만 표시. 다시 누르면 이전 표시 조합을 복원합니다. 카메라와 선택은 유지합니다.
- **형상 확인:** 단색 재질과 경계·정점·격자·축 표시. 양면 렌더링으로 뒤집힌 면을 감추지 않습니다.

표시 조합은 프로그램 설정 파일에 저장하며 문서의 수정 상태나 Undo 이력에 넣지 않습니다. 기존 메시 좌표 캐시와 이미지 캐시를 재사용합니다. 순수 미리보기도 OMSI/openOMSI 엔진과 동일한 렌더러는 아닙니다.

## 호환성 및 확인 범위

기존 SLI 및 프로젝트를 열기만 하면 UV를 바꾸지 않습니다. 프로젝트 형식은 7로 저장하며 형식 1~6을 읽습니다. 이전 프로그램에서는 형식 7을 열 수 없습니다. 새 메타데이터는 SSPROJ에만 저장하고 SLI에는 최종 UV만 기록합니다.

주요 변경: `src/SplineStudio.Core/UvBoundary.cs`, `RoadComponents.cs`, `TextureEditing.cs`, `SliDocument.cs`, `Modules.cs`, `LibraryStorage.cs`, `src/SplineStudio/MainWindow.Boundary.cs`, `MainWindow.PreviewDisplay.cs`, `MainWindow.MaterialInspector.cs`, `MainWindow.RoadAtlas.cs`, `SplineSceneRenderer.cs` 및 기존 설정/편집 연동 파일.

아틀라스 일부 띠를 가로로 반복할 수 없는 기존 SLI 표현 한계와 scaleTexByLength/patchwork 전문 편집 안내는 유지합니다. 보정은 인접 픽셀 번짐을 줄이기 위한 기능이며 모든 밉맵/엔진 조건에서 선이 없어짐을 보장하지 않습니다. 실제 텍스처에 그려진 선은 순수 미리보기에서도 남습니다.

새 외부 라이브러리는 없습니다. Release 빌드와 기본 실행만 확인하며 종합 테스트·반복 UI·성능·인게임/nEditor 검증은 수행하지 않습니다. 참고 SLI·원본 텍스처는 수정하거나 배포하지 않습니다.

- 연결된 요소는 실제 끝점을 다음 시작점으로 공유합니다. 자동 면 이동 시 원래 매개변수로 좌표를 일관되게 계산하고, 연산 순서에 따른 경계값 차이를 방지합니다. 독립 수동 면, 의도된 단차/간격은 유지합니다. 기존 프로젝트를 열 때 강제로 형상을 다시 만들지 않습니다.
- 목록 순서 버튼을 ▲/▼로 바꾸고 선택 및 양 끝 상태에 따라 비활성화합니다.
- **설정 > 테마**에서 어두운 / 밝은 / 시스템 테마를 실시간 선택합니다. Windows 앱 테마 변경 이벤트를 따르며 환경설정에 저장합니다. 프로젝트·카메라·실행 취소 이력과 별도로 관리합니다.
- 공통 팔레트와 DynamicResource 스타일을 사용합니다. 기본 WPF 메뉴 팝업 템플릿에 남던 밝은 테두리를 전용 메뉴/컨텍스트/구분선/툴팁 템플릿으로 교체했습니다.

제한 및 확인 범위: 실제 문제가 발생한 사용자 SLI는 찾지 못했습니다. 참고 SLI와 생성 코드만 직접 분석했으며, 황갈색 선이 형상 틈인지 텍스처 필터/밉맵 번짐인지 nEditor 오버레이인지는 확정하지 못했습니다. 원본 텍스처·UV 영역은 임의 축소하지 않았고, 면을 겹치거나 추가하지 않았습니다. scaleTexByLength/patchwork는 기존처럼 전문 UV 편집을 사용하세요. 일부 영역의 물리 비율 매핑은 선택 띠 내부의 가로 반복을 지원하지 않습니다.

빌드와 기본 실행 및 위 오류에 직접 관련된 데이터 확인만 수행했습니다. 종합 자동화·회귀·테마별 UI 전수·성능·장시간·OMSI/openOMSI/nEditor 적용 검증은 수행하지 않았습니다. 새 외부 라이브러리는 없습니다. 참고 파일은 읽기 전용으로 사용했으며 배포하지 않습니다. 프로젝트 형식은 6을 유지합니다.

## 시작하기

1. 첫 화면에서 **새 스플라인 만들기**를 누릅니다. 빈 스플라인, 도로, 보도, 연석 등으로 시작할 수 있습니다.
2. 도로의 차로 수·방향·폭, 양쪽 보도·연석·갓길·중앙분리대와 자동 경로를 지정합니다. 아래 단면 미리보기와 전체 폭이 바로 갱신됩니다.
3. 왼쪽 구성요소를 선택하고 오른쪽 치수를 입력한 후 **형상 적용**을 누릅니다. Ctrl/Shift로 다중 선택할 수 있습니다. 목록 드래그와 ◀/▶로 순서를 바꿉니다.
4. 표면별 텍스처를 선택하고 **영역 선택**에서 이미지의 가로 띠를 지정합니다. 픽셀 입력·스냅, 영역 이동·크기 조절, 확대·이동, 이름 있는 영역 저장을 지원합니다. **매핑 적용**으로 반복 거리와 실제 폭 비율을 적용합니다.
5. `.ssproj`에는 구성요소·이력 대상 상태·연결·UV·자동 경로 소유 관계가 저장됩니다. 게임에는 **파일 > SLI 내보내기**를 사용합니다.

## 구성요소 편집

차로·보도·연석·중앙분리대·배수로·갓길·사면·버스베이·평면·벽을 실제 SLI 면으로 생성합니다. 연결점에 따라 높이와 이웃 위치가 이어지며, 변경한 요소만 재생성하고 나머지는 이동합니다. 자동 차량/보행 경로는 요소의 중앙과 표면 높이를 따릅니다.

전체 중심·차도 중심·양 끝·선택 연결점 및 사용자 좌표를 기준으로 배치합니다. 복제·반대편 복제·전체 대칭·대칭 쌍 연결을 제공합니다. 편집기 숨김과 SLI 제외는 별개입니다. 구성요소 등록과 전체 사용자 프리셋은 기존 라이브러리를 사용합니다.

상단 **전문 모드**에서 기존 정점·면·UV·재질·경로·라이브러리·참조 이미지 기능을 사용할 수 있습니다. 모드 전환은 형상을 재생성하지 않습니다. 자동 면을 직접 수정하면 수동 상태가 되며, 자동 복원은 별도 확인 후 수행합니다. 전문가가 수정/삭제한 경로는 자동 경로 소유 관계에서 분리됩니다.

## 제한사항

- 기존 SLI는 전문가 화면으로 열립니다. **기본 모드**에서 후보를 확인하거나, 전문가 화면의 **선택 면 → 구성요소**로 의미를 부여하세요. 평면·벽·사면 후보만 제시하며 차로/보도를 임의로 단정하지 않습니다. 수동 형상의 자동 변환은 원래 정점/UV를 교체합니다.
- SLI의 U 띠와 진행 방향 반복만 편집합니다. 세로 부분 자르기/V 시작 오프셋은 지원하지 않습니다. 아틀라스 일부 영역을 가로 반복하는 요청은 제한합니다. scaleTexByLength/patchwork는 전문가 UV에서 편집하세요.
- 수동 구성요소 복제·세밀한 자유 형상은 전문가의 기존 복제/라이브러리 기능을 사용하세요. 기본 모드의 형상 적용은 자동 구성요소에 해당합니다.
- 대칭 연결은 치수·기울기·표면 매핑을 연동합니다. 임의의 수동 정점 대칭 연결은 제공하지 않습니다. 독립 배치 요소는 자동 연결을 끄고 X/Z를 지정합니다.
- 버스베이는 일정 폭 단면만 지원합니다. 변폭·진입/진출부·교차로·테이퍼는 포함하지 않습니다. 자동 차선 도색 생성은 제공하지 않습니다.
- 새로운 구성요소 문구는 한국어입니다. v0.5 영어 번역은 기존 기능에 적용됩니다.
- 프로젝트 형식 6으로 저장하며 형식 1~5도 읽습니다. 이전 프로그램은 형식 6을 열지 못합니다. SLI에는 새 전용 명령을 기록하지 않습니다.
- 지정된 Asphalt_dark-Granite path_type1 샘플은 분석에만 사용했습니다. 제3자 텍스처와 SLI 원본을 배포 ZIP에 포함하지 않았습니다. 새 외부 라이브러리는 없습니다(Pfim MIT 유지).

Release 빌드와 최소 실행만 확인합니다. 종합 자동화·회귀·UI 전수·게임 호환성·장시간 안정성·성능 검증은 이번 작업에 포함하지 않습니다.

## 새 제작 기능

- 사용자 프리셋 및 구성요소 라이브러리: 왼쪽 라이브러리 탭에서 선택한 면/경로 또는 전체 프로젝트를 등록합니다. 이름·카테고리·설명·제작자·태그·즐겨찾기, 검색, 썸네일, 최근 사용순 정렬을 지원합니다.
- 리소스는 원본 텍스처를 복사해 실행 폴더의 UserLibrary에 저장합니다. 사용자 설정에서 위치를 변경할 수 있습니다. 기본 프리셋은 별도이며 삭제 대상이 아닙니다.
- 구성요소는 기준점·연결점·좌표·선택 정점·좌우 끝에 배치하며, 반투명 미리보기 또는 마우스 배치를 사용합니다. 라이브러리 항목을 2D 화면으로 끌어 놓을 수도 있습니다.
- 좌우/상하 반전, X/Z 개별 배율과 UV 유지 옵션을 제공합니다. 그룹 탭에서 이름·카테고리·기준점·연결점·표시·잠금·이동·변형·복제·그룹 해제·삭제를 관리합니다.
- 파일 > 부분 가져오기 / 스플라인 병합에서 SLI/SSPROJ의 면과 AI 경로를 선택합니다. 텍스처는 실제 파일 내용과 재질 설정을 비교하여 재사용하고 참조 번호를 재매핑합니다.
- 라이브러리의 .sslib 가져오기/내보내기는 여러 항목과 텍스처 포함 여부를 지원합니다. 공유할 텍스처의 재배포 권한은 사용자가 확인해야 합니다.

## 정밀 편집

Ctrl+정점 클릭 또는 상세 정점 표에서 다중 선택합니다. 편집 > 정밀 편집 관련 메뉴에서 정렬·균등 배치·좌표 결합·이동·배율·목표 크기·비율/개수 면 분할·반복 복제를 사용합니다. 조작은 한 번의 실행 취소로 복원합니다.

SLI는 면마다 정점을 별도로 저장합니다. 정점 병합은 선택 점의 좌표를 일치시키며 재질·UV 경계의 별도 점은 유지합니다. 안전한 정리는 같은 UV를 가진 연속 중복과 중복/0길이 면을 대상으로 합니다. 독립적인 전역 정점 인덱스나 사용되지 않는 독립 정점은 SLI에 없습니다.

고급 스냅은 격자·정점·면·중앙점·축·원점·경로·연결점·각도를 선택하고 화면 px 기준 감지 거리와 우선순위를 설정합니다. 정점/경로 이동과 구성요소 마우스 배치에 연결됩니다. Alt를 누르는 동안 스냅을 해제합니다. 치수 측정은 m/cm/mm 표시를 지원하며 실제 SLI 좌표는 항상 m입니다.

## 참조 이미지

왼쪽 참조 이미지 탭에서 이미지를 추가하고 위치·크기·회전·투명도·반전·표시·마우스 이동 잠금을 설정합니다. 두 지점 실제 거리 보정으로 스케일을 맞춥니다. 이미지 좌표는 왼쪽 위 X/Z이며 높이는 아래 방향입니다. 참조 이미지는 프로젝트 .assets/references에 복사하고 SLI에는 내보내지 않습니다. 사진 원근 보정은 제공하지 않습니다.

## 문서와 데이터 보호

- 문서 탭마다 형상·UV·경로·선택·이력·미리보기·카메라/확대 상태를 유지합니다. 동일 파일은 기존 탭으로 전환합니다.
- Ctrl+C/V는 정점 또는 면/경로를 프로젝트 사이에서 복사합니다. 면 붙여넣기는 공통 병합 처리를 사용해 텍스처·재질을 가져옵니다. 정점 붙여넣기는 대상 면을 선택해야 합니다.
- 자동 저장 기본 5분, 보관 10개입니다. 설정에서 0/1/3/5/10/15/30분과 보관 개수를 변경합니다. 변경된 문서만 Backups에 기록하며 원본 SLI/프로젝트를 자동 덮어쓰지 않습니다.
- 비정상 종료 기록이 있으면 다음 실행에서 복구 목록을 제공합니다. 복구 문서는 원본과 분리하여 저장합니다. 파일 > 자동 백업 관리에서도 열 수 있습니다. 자동 백업은 형상/설정 데이터이며 원본 이미지가 삭제된 경우 별도 재지정이 필요합니다.
- 프로젝트 저장 형식은 v5입니다. v1~v4를 읽으며 기존 파일은 열기만으로 변경하지 않습니다. .ssproj와 .assets를 함께 이동하세요. v5는 이전 실행 파일에서 열 수 없으므로 필요하면 다른 이름으로 저장합니다.

## 검사·언어·제한

유효성 검사는 오류/경고/정보와 관련 요소·수정 안내를 표시합니다. 목록에서 문제 위치로 이동하고 확인 후 안전한 정리 또는 선택 텍스처로 잘못된 참조를 복구할 수 있습니다. UV가 0~1 범위를 넘는 정상 반복은 오류로 취급하지 않습니다.

한국어/영어 전환은 프로그램 설정에서 제공합니다. 공통 메뉴·도구·주요 속성·설정은 영어 리소스를 사용하며, 아직 번역되지 않은 동적 설명·일부 선택 목록과 진단 메시지는 한국어로 표시됩니다. 사용자 이름·파일명·SLI 데이터는 번역하지 않습니다.

미지원 명령의 참조 의미를 유지할 수 없는 전체 병합은 제한합니다. 부분 가져오기는 제외되는 명령을 안내하고 확인을 받습니다. 원본 파일은 수정하지 않습니다. 그룹·기준점·연결점·참조 이미지는 프로젝트 메타데이터이며 새로운 SLI 명령을 만들지 않습니다.

마우스 지정점/거리 입력에 의한 면 분할, 부분 가져오기 단계의 자동 근접 정점 병합, 정점 사각형 선택, 모든 UI 문자열의 영어 번역은 이번 구현에 포함되지 않았습니다. 면 분할은 비율/개수, 근접 정리는 가져오기 후 명시적 정리 명령을 사용합니다. 그룹 이동/변형은 속성 창에서 수행합니다.

곡선/경사는 배치 미리보기이며 실제 맵 배치는 에디터에서 지정합니다. 가변 폭·전환 스플라인·교차로 자동 생성·PBR·온라인 공유·클라우드·계정·플러그인 시스템은 범위에 포함하지 않았습니다.
